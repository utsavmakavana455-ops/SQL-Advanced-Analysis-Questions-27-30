# SQL Advanced Analysis — Questions 27–30

## 📊 Project Overview

This project contains 4 practical SQL problems using a **100-row e-commerce orders dataset**.

The focus is on customer analysis, product performance, subqueries, and time-based sales analysis.

## 📝 Questions Covered

* **27.** Find the highest order for each customer
* **28.** Find customers whose average order value is above the overall average
* **29.** Find the most popular product by quantity sold
* **30.** Calculate month-over-month sales and sales difference
